# 主题、原图与作者打赏修复记录

主题滑块与底部 Dock 的尺寸和操作保持原有定义。主题进度不再每帧写入 `html.style`；这次写入曾导致完整样式树重复计算。合成路径仅调整画面透明度与滑块位移，兼容路径批量读取可见内容配色，排除不存在的边框，把背景动画放在无子节点的临时图层。画面捕获超过 350ms 时从当前手指进度继续兼容动画，取消、离开页面和收尾均清理图层。

照片上传与墙面加载共享内联 SVG 花园，茎叶逐笔生长、花瓣展开后轻轻摇动。动画不伪装网络进度；XHR 字节事件推动传输进度，存储和记录保存分别等待确认。原始 PNG、EXIF JPEG 和 GIF 通过真实编码文件验证 SHA-256、完整尺寸和方向；后端没有重编码或衍生图写入。原图仍受既有文件体积与像素上限约束。

“作者打赏”后台上传静态 PNG、JPEG 或 WebP 收款码，单张不超过 2MB。普通用户在管理员会话顶部打开二级弹窗，可见微信、支付宝及小字说明；未设置的收款码有明确空状态。配置保存在已有内部管理记录中，不需要数据库迁移。二维码替换使用新地址，失败保留旧地址，避免缓存旧码。

私有附件签名失败现在隔离到单条附件，消息文字与已保存的转写仍可读取。完成队列文字在会话读取时恢复，浏览器合并迟到快照时也保留已有转写。转写提供商、服务凭据和录音格式策略沿用现有实现；本轮没有调用真实语音转写服务或创建新密钥。

四倍 CPU 降速、1024×768、30 条动态的同条件拖动采样中，35 帧的第 95 百分位帧间隔从原实现约 375ms 降到合成路径约 31ms；强制兼容路径约 112ms。首次拖动输入等待从约 898ms 降到约 297ms。软件浏览器、模拟 CPU 与固定场景的结果不能保证所有物理设备的帧率，也不代替 iPhone／iPad 触摸、麦克风与双设备联调。

发布前验证：852 项运行测试及补充检查、语法、构建和构建一致性检查均通过。相关 Chromium 回归共 97 项通过；Linux WebKit 共 80 项通过，3 项依赖 Chromium 触摸协议或云环境未提供的录音能力而跳过。测试页补齐移动端视口，原图用 HTTP 接收端核对实际文件字节，迟到响应使用显式释放控制，避免网络计时和浏览器请求体检查器造成假结果。失败项修正后均复测通过。所有本地浏览器接口采用测试数据，不写生产数据库；发布后的部署状态通过 Render 核对。

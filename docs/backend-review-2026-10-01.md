# 2026-10-01 聊天闪图与后台检查

本轮检查范围：聊天附件与撤回、个人导出、额度与 Pro、行为记录、管理员用户详情、GPS 历史、Supabase Storage/RPC 权限。属于针对这些功能的人工检查及回归验证，不能视为全站无漏洞保证。

## 已修复和新增

- 闪图只在私有 `dm-flash` 桶保存 AES-256-GCM 密文；普通消息和导出只含占位信息，不包含照片 URL、存储路径或解密密钥。数据库表和 RPC 仅允许后端 service_role；Storage 增加独立 restrictive 策略，防止未来宽泛策略放行。
- 发送者不限次自查看；接收者通过受限预留、加载呈现和幂等确认完成一次查看，服务端确认后禁止接收者再次领取。发送者的私有密文副本不因接收者查看删除。清空会话、个人隐藏、撤回、账号删除后同名注册不能绕过查看权限；管理员也不能查看不属于自己的闪图。撤回立即清除密钥，后台持续清理失效密文。
- 接收者浏览器加载、解码及呈现后展示 3 秒，发送者不限次自查看且不计时；时间到、关闭、切换账号/会话、离开聊天或页面隐藏立即清除图片 src 并撤销 Blob URL。退出动画只保留背景，不延长清晰图片展示。过期后的旧气泡和迟到响应不能恢复预览。
- 普通账号默认每日 3 张，Pro 默认 20 张；管理员默认不限。个人设置优先，统一覆盖可主动清空个人设置并统一所有账号（包括管理员）的额度。按北京时间零点切换额度日。发送事务使用账号锁，重试使用唯一 client_id，避免并发超额、重复扣费。支持静态 JPEG/PNG/WebP，20MB；聊天原图开关决定是否压缩，照片墙保留原文件；同时最多处理两次闪图上传。
- 私有密文为发送者自查看保留至撤回、删除或账号删除；接收者下载、解码失败不消耗。查看预留隔离并发页面，同页面失败重试复用查看标识；预留 60 秒后释放。清理失败逐对象重试，不覆盖首次查看时间。旧版已销毁密钥无法恢复。
- 最近用户行为改为服务端记录认证后操作及状态：发送、闪图、发帖、照片、评论、点赞、导出、授权定位、AI 使用及拒绝操作。账号、IP、时间由服务端确定；不保存聊天输入、密码、剪贴板或请求正文。快速重复浏览/导出/AI 事件合并，写入操作分别保留。沿用行为日志 30 天清理。
- GPS 管理界面只显示最近 50 条，服务器也限制为 50；保留历史不删除，用户自己的分页和个人导出仍读取所有保留记录。
- 修复 IP/设备统计按倒序处理时把“最后出现时间”写成旧记录的问题。
- Supabase 检查发现 8 个旧管理 RPC 可匿名执行，其中封禁详情包含管理员原因与操作人。前端没有这些函数的调用；现限制为 service_role，并固定 13 个旧函数的 search_path。原有触发器及后端配额逻辑不变。

## 能力边界

本功能实现网站正常接口的一次性查看，不能阻止截图、录屏、外部相机或修改浏览器保存已经收到的字节；不提供浏览器 DRM 承诺。服务商历史备份与底层存储的物理擦除无法由网站代码保证，也不能宣称管理员或数据库备份完全不可恢复。管理员能查看依法收集并保留的账户和安全记录，不意味着能读取设备中未上传、未授权的全部资料。GPS 仅记录用户主动授权的位置，不持续后台跟踪。

安全记录通过响应结束后写入数据库；数据库故障时记录警告，避免阻断用户操作。本版尚未实现可靠事件队列，极端情况下可能漏记。历史已丢失的行为或登录事实不回填、不编造。Supabase 的“RLS 无策略”提示对 service-only 表属于预期拒绝访问；本轮应复核新表/RPC、封禁 RPC 和 Storage，不为消除提示增加浏览器读取策略。

## 后续建议

1. 为关键安全事件增加有界持久队列、失败计数和告警，减少数据库短时故障造成的漏记；同时明确队列与日志保留期限。
2. 在后台汇总新设备登录、连续认证失败、频繁越权请求和大额导出，提供按账号查询与异常阈值；用既有会话记录，避免新增精细指纹。
3. 将管理员查看用户详情、GPS、修改额度及导出纳入统一审计页，显示结果、服务端时间和操作者；提供日志保留规则及用户可见的数据用途说明。

测试覆盖 Node 接口、真实数据库回滚事务、Chromium 和 Linux WebKit。模拟浏览器不等同于物理 iPhone/iPad 与真实双账号双设备验收。

## 本轮验证结果

- 全量 `npm test`：898 个 Node 测试、99 个补充检查通过；语法与构建一致性检查通过。
- 聊天浏览器回归：102 个用例通过、2 个 CDP 条件用例跳过；包含对环境断开及旧测试隔离问题的复测。后台用户详情与个人/统一闪图设置在 Chromium、Linux WebKit 各通过一次。
- 真实数据库事务验证（全部回滚）：默认/Pro/个人额度、幂等发送、旧版首个查看、撤回、个人隐藏、清空、过期及账号删除后同名重建（新规则在后续修复中另行验证）；临时测试账号及消息未留存。
- Supabase 复检仅剩预期的 service-only 表 RLS 无浏览器策略提示，无 WARN 级安全告警。

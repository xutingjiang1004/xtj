# 聊天页面 UI 与动画优化（2026-09-30）

基于 `cd23ce7a`，本次仅调整聊天页面与相关浏览器测试，底部 Dock 的结构、样式与动画保持原样。

## 交互变化

- 会话列表删除每一行的三个点。会话管理统一由打开对话后右上角的三个点进入，包含搜索、媒体、置顶、归档、免打扰、已读／未读、清空和删除。好友、归档列表入口留在会话列表工具栏，桌面分屏下仍可使用。
- 对话顶部与输入区统一图标、间距、圆角及浅绿配色；改善深色模式、时间与已读状态对比度。搜索与好友面板减少整页模糊。
- 会话菜单打开 200ms、关闭 140ms，支持 Escape、焦点回到入口、Tab 焦点循环。快速关闭后重开会取消旧动画，旧回调不会把新菜单隐藏。
- 消息长按菜单缩短位移与缩放，退出时停止接收点击；滚动时跟随原气泡，原气泡离开视口才关闭，避免浏览器自动滚动误关菜单。
- 发送文字、照片时，根据输入框／附件缩略图的实际位置，执行 380ms 位移、缩放及淡入。确认消息时不重复播放；图片解码前预留缩略图尺寸，避免初始 0×0 导致跳过动画。切换会话、离开聊天、隐藏页面、调整窗口或清空消息会清理动画。
- 继续使用已有后端好友范围的在线、最后在线及临时输入通知。输入状态增加动态小点，4.7 秒过期后立即恢复最后在线显示；忽略其他会话和过期事件，切换会话停止旧会话输入通知。
- 尊重系统减少动态效果和站内“动效关闭”设置。

## 验证

- 完整单元测试 839/839，既有补充测试 99/99；好友、在线、输入与已读后端运行测试 12/12。
- 聊天浏览器回归 15/15，包括新增菜单位置／快速重开、文字与照片飞出、快速服务端确认、输入状态过期、切换会话清理以及动效关闭。
- 聊天视觉回归 4/4，长按操作与转发菜单另重复运行 3 次通过。
- 生产资源重建、语法及产物一致性检查通过。底部 Dock HTML 与本次基线逐字一致，未修改 Dock CSS 规则。

浏览器测试使用模拟 API、音频设备和 Chromium。没有将这些结果当成真实双设备或 iPhone Safari 验收。实际触屏、键盘与帧率体验仍需真机确认；推送代码也不代表已核实 Render 部署完成。

## 四、生产环境核对/操作指引（Supabase 与部署）

1. **在 Supabase SQL Editor 执行 `supabase/migrations/055_audit_fix_2026-09-04.sql`**（含 M64/M66/M67 与 L 级 SQL 加固；**先于 055 确认 render-api 已部署**，因 server.js 已同步传 `p_is_admin`）。
2. 核对报告 S 级「历史窗口」两项：
   - `SELECT policyname FROM pg_policies WHERE tablename='posts'`：应无 `avatar_userinfo_select`；`posts_public_feed_read` 不应含 `__user_info__`。
   - `pg_proc` 中 `claim_pro_gift(text,text)`（2 参版本）应不存在。
3. Render 部署：如需保留管理员私信未读邮件提醒，设置 `ADMIN_DM_NOTIFY_EMAIL` / `ADMIN_DM_NOTIFY_USER`（未设置则提醒功能不启用，私信不外发）。
4. 管理端已登录会话不受影响；普通用户登录/刷新在 Supabase 正常时无感知（仅当限制查询 RPC 不可用时返回 503，属安全收紧的预期行为）。

# 更新日志

## v0.0.44 - 2026-05-25
### 修复
- 彻底修复照片左右滑动黑屏问题：重构 `ppNavigatePhoto` 逻辑，在滑动动画开始前先正确重新排布三个槽的图片，确保用户在滑动过程中看到连续的图片而非黑屏
- 修复放大图片后无法单击返回的问题：修改 `document.addEventListener('click')` 回调，现在点击图片区域时，如果图片已放大则先缩小到 1 倍，未放大则直接关闭预览
- 修复照片全屏预览重叠显示问题：移除导致重叠的 View Transitions API 相关代码，仅保留 CSS 淡入动画
- 修复照片删除后刷新重新出现的问题：新增 `photoWallDeletedKey` 本地删除 ID 追踪机制，加载时自动过滤已删除照片；删除时同步删除云端记录和 Storage 文件
- 增强健壮性：添加 overlay 空值守卫，清理无效删除记录等

## v0.0.43 - 2026-05-25
### 性能与体验优化
- GPU渲染降级（移动端适配）：移动端触摸设备上自动降低毛玻璃模糊强度，显著减少发热与卡顿
  - 基础毛玻璃：从 blur(38px) 降至 blur(12px)
  - 底部导航栏：完全移除 backdrop-filter
  - 照片预览遮罩层：降至 blur(4px)
  - 使用媒体查询 @media (hover: none) and (pointer: coarse) 智能检测触摸设备
- 主线程阻塞修复：compressImage 函数优先使用 createImageBitmap 将图片解码/缩放移出主线程，避免大图压缩时浏览器假死，不支持的浏览器自动回退到传统方法
- 原生级视图过渡：View Transitions API 实现照片预览打开/关闭的丝滑动画，自动降级兼容
- 沉浸式环境光背景：Canvas 提取照片主色调，全屏预览背景随照片切换动态变化（辐射渐变）
- 状态与DOM解耦：新增 appState 命名空间、safeText 安全转义函数、虚拟滚动规划注释，增强代码安全性和可维护性

## v0.0.41 - 2026-05-25
### 更新内容
- 照片墙UI/UX全面增强
  - 图片淡入加载（Blur-in Lazy Load）：图片进入视口时从模糊到清晰渐显，使用 IntersectionObserver 懒加载，减少初始带宽占用
  - 卡片悬浮微动（Hover Lift）：鼠标/手指经过照片卡片时卡片轻轻浮起（translateY(-4px) + scale(1.02)），阴影加深，提供即时的交互反馈
  - 交错入场动画（Staggered Entrance）：照片卡片首次加载时从底部依次弹入，每张延迟 50ms，类 iOS 相册入场效果
  - 骨架屏加载（Skeleton Cards）：数据加载期间显示 6 个脉冲动画灰色占位卡片，替代空白网格
  - 空状态引导优化：无照片时显示大号上传按钮"成为第一个分享照片的人"，降低操作门槛
  - 预览页面指示点（Page Dots）：全屏预览顶部居中显示圆点，当前照片高亮，一眼知晓位置和总张数
  - 照片删除功能：预览模式左下角显示删除按钮，点击弹出液态玻璃确认弹窗，仅照片上传者可见
  - 快捷分享按钮：预览模式右下角链接图标，支持原生分享 API / 剪贴板复制 / 兜底复制，复制后 toast 提示
- 液态玻璃效果覆盖
  - 照片墙标题栏：sticky 吸顶液态玻璃模糊，半透明背景 + 内阴影高光 + 圆角卡片风格
  - 上传按钮：从纯色渐变改为绿色调液态玻璃（绿色微透明底 + blur(12px) + 绿色描边），暗色模式亮绿配色
  - 消息通知横幅：顶部居中滑入，高强度液态玻璃（blur(28px) + saturate(200%)），头像增大至 48px，双层内阴影模拟玻璃厚度感
